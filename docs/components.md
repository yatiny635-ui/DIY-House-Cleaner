# Components

| Component | Quantity | Purpose |
|---|---:|---|
| Arduino UNO | 1 | Main controller |
| L298N motor driver | 1 | Drives the two wheel motors |
| L9110S dual motor driver | 1 | Drives the two side-brush motors |
| Witty Fox 3.7V 2600mAh Li-ion battery | 2 | 2S battery pack |
| 5V buck converter | 1 | Regulated 5V supply |
| ON/OFF switch | 1 | Main power control |
| BO/DC gear motor | 2 | Drive motors |
| DC motor | 2 | Side-brush motors |
| Cleaning brush | 2 | Sweeping mechanism |
| Wheel | 2 | Drive wheels |
| Caster wheel | 1 | Chassis support |
| Jumper wires | As required | Electrical connections |
